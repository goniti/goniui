# goniui

## 0.1.2

First public release.

- ~50 React components for Tailwind CSS v4 on Radix primitives: atoms (`Button`, `Input`, `Select`, `Switch`, `Text`, `Flex`…), molecules (`Dialog`, `DropdownMenu`, `Tabs`, `Toast`, `Calendar`, `Agenda`, `Carousel`, `Form`…) and the `DataTable` organism; compound components under their own subpath (`goniui/dialog`…).
- Neutral black & white theme with a dark mode (`.dark` on `<html>`), re-skinned through CSS variables; `goniui/styles.css` brings the tokens, a reset, the animations and the `@source` directive.
- Next.js App Router ready (`'use client'` directives) and Node ESM compatible (full import paths).
- Live demo and Storybook: https://goniti.github.io/goniui/
- Published from CI through npm trusted publishing, with signed provenance.
